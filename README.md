## 📚 Collection Data Structures (Java)

This project is a custom implementation of core data structures in Java, built for learning and understanding how collections work internally. It includes implementations of lists, sets, maps, queues, and trees without relying on Java’s built-in collection framework.

### ⚙️ Included Structures
- ArrayList  
- LinkedList  
- HashSet  
- Map  
- Queue  
- TreeSet  

### 🎯 Purpose
The goal of this project is to strengthen knowledge of data structures, algorithms, and object-oriented programming by building everything from scratch.

### 🚀 Usage
You can run and test the implementations using the `Test.java` file.
